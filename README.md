# Transformer《红楼梦》风格文本生成

简体中文 | [English](README.en.md)

一个适合学习和通过手搓理解Transformer架构的《红楼梦》文本生成项目。使用 PyTorch 从零实现字符级自回归语言模型。模型仅使用曹雪芹所写的《红楼梦》前 80 章文本作为训练语料，根据给定上文逐字生成续写内容。

本项目用于学习语言模型的数据处理、因果自注意力、多头注意力、残差连接及训练与采样流程。模型从随机初始化开始训练，不依赖预训练语言模型。

```text
└── hong_lou_meng_80.txt     # 训练文本，代码按 gb18030 编码读取
```

## 模型与训练配置

模型由字符嵌入、可学习的位置嵌入、多层 Transformer Block、最终 LayerNorm 和词表投影层组成。每个 Block 使用带因果掩码的多头自注意力、前馈网络及残差连接，采用 Pre-LayerNorm 结构。

| 配置项 | 默认值 |
| --- | --- |
| 分词方式 | 字符级，词表由语料中出现的字符构建 |
| 上下文长度 | 64 个字符 |
| Batch size | 256 |
| 嵌入维度 | 384 |
| 注意力头数 | 8 |
| Transformer 层数 | 6 |
| 前馈网络隐藏维度 | 1536 |
| Dropout | 0.2 |
| 优化器 | AdamW |
| 学习率 | 0.0005 |
| 训练步数 | 1000 |
| 评估间隔 | 100 步，另在最后一步评估 |
| 每次评估 | 训练集和验证集各采样 200 个 batch |
| 数据划分 | 前 90% 为训练集，后 10% 为验证集 |
| 生成长度 | 500 个字符 |

训练目标是预测下一个字符，损失函数为交叉熵。生成时对最后一个位置的预测分布进行 multinomial 随机采样。

## 环境准备

需要 Python 和 PyTorch。

在已有 Python 环境中安装基础依赖即可：

```bash
python -m pip install torch
```

如需运行 Notebook：

```bash
python -m pip install notebook
```

GPU 环境中的 PyTorch 安装方式应与服务器驱动及 CUDA 环境匹配。代码在 `torch.cuda.is_available()` 为真时使用 CUDA，否则使用 CPU。默认配置在 CPU 上训练可能较慢，显存不足时可先减小 `batch_size`。

## 运行方法

### Python 脚本

将 `hong_lou_meng_80.txt` 放在项目根目录，进入该目录后运行：

```bash
python transformer.py
```

脚本会读取文本、建立字符词表、训练模型并打印训练集和验证集损失。训练完成后，从验证集中随机选取 64 个字符作为上文，生成 500 个字符，并打印上文、生成内容与真实下文供对照。

### Notebook

```bash
jupyter notebook test.ipynb
```

Notebook 保留了 Google Colab 环境配置，数据路径为 `/content/drive/MyDrive/hong_lou_meng_80.txt`。在本地或学校服务器运行前，需要改为实际数据路径，并跳过 Google Drive 挂载单元格；在 Colab 中使用时，应先挂载 Drive 再执行读取数据和训练的单元格。

## 当前可能的待改进项

- 上下文窗口仅为 64 个字符，难以捕捉长篇叙事关系。
- 尚未保存或加载模型权重、词表及训练状态；重新运行会重新训练。
- 生成前尚未切换到 `eval()` 模式，也未关闭梯度计算，Dropout 仍会生效。
- 注意力掩码固定为完整上下文长度；支持较短提示词前，需要按实际序列长度切片。
- `LanguageModel` 中保留了未参与前向计算的 `multi_head` 层，参数统计包含该层。
- 仅固定了 PyTorch 随机种子，Python 的 `random` 未固定，结果不保证完全可复现。
- 当前文件在顶层调用 `main()`，导入脚本也会开始读取数据和训练。
